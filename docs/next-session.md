## 実機確認の進め方

自動化できる確認をCodexがまとめて実行し、本人は権限操作と最後の目視確認を担当する。本人に自動確認を一項目ずつ委ねない。端末が自動ロックされたらその都度本人へ解除を依頼し、自動ロック設定を勝手に変更しない。ロック画面の内容・暗証番号は取得しない。

SDK側ADBを使い、現在接続中の端末・Wi-Fiポートを確認する。複数接続が同一実機かは内部で確認できるが、端末シリアルを出力・公開しない。写真・画面・ローカルの確認スクリプトは `captures/` と `.tools/tmp/` に置き、Gitへ追加しない。

アプリ変更後は `scripts/build.ps1` と変更に応じたテストを実行する。文書のみならビルドを繰り返さず整合性と `git diff --check` を確認する。
