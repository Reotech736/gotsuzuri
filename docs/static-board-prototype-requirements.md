# 静止画像の四隅指定・交点表示の要件

合意日: 2026-10-19

grillingによる相談後、以下の共有理解を本人が確認し、文書化に合意した。対象は直近の撮影検証とステップ3の試作であり、全MVPの仕様ではない。現在地はステップ1完了のまま。今回実施したのは相談と文書化のみで、ステップ2の実機確認・ステップ3の実装は未実施。

## 目的と初期利用シナリオ（確定）

長期的な目的は、実盤での対局中に毎手スマホを操作する負担をなくし、対局後に不確かな区間を修正してSGFを残すこと。

最初の検証は、自宅の19路盤と碁石を使い、撮影位置と石の配置を自分で調整できる環境で行う。対局を通して記録する段階ではなく、静止画像で盤面の位置合わせを確かめる。

## 撮影条件と検証範囲（確定）

- まず卓上式スマホスタンドを使う。真上からの撮影やアーム式を開始条件にしない。
- 普段の室内照明で、同じ設置位置から「空の盤」と「黒白の石を盤全体に分散して置いた盤」を撮影する。
- 盤全体と最外周四隅の交点が写り、人が指定できることを最低条件にする。指定対象は盤の木枠の角ではない。
- 四隅の交点が見えなければ、撮影位置や石の配置を調整して撮り直す。
- 卓上式でうまくいかなければ、結果を見て高さの調整やアーム式を検討する。設置変更は現時点で必須にしない。

## 試作の操作と要件（確定）

1. アプリで撮影した直後の静止画像を使う。保存画像の選択は含めない。
2. 画像上の左上→右上→右下→左下の順に、最外周四隅の交点をタップする。指定順を画面に案内する。
3. 19×19の交点を静止画像に重ねて表示する。
4. 4点指定後、各隅をドラッグして位置合わせを微調整できる。
5. 重ねた交点を見て位置合わせを確認する。

撮影後の指定から微調整・確認まで、慣れれば1枚あたり1〜2分以内を目標とする。これは許容する操作負担の目安で、達成済みの測定値や性能保証ではない。実測して見直す。

今回は画像上の左上等を基準とする。SGFなど対局記録としての盤の向きは、この試作では決めない。画像座標と論理碁盤座標を分離する既存方針を維持する。

## 成功条件（合意済み・達成は未確認）

- 撮影直後の画像で、指定順に4点を選び、19×19交点を表示できる。
- 四隅をドラッグして修正し、位置合わせを確認できる。
- 空の盤では、四隅・各辺の中央・盤の中央で、表示点が対応する実際の交点に重なって見えることを人が確認できる。
- 石を並べた画像でも、見える交点のずれを確認できる。石の下や石に隠れた交点の可視性は要求しない。
- 位置合わせの所要時間を実測し、1枚あたり1〜2分という目安と比較する。

位置合わせはまず目視で評価する。ピクセル単位の誤差上限や認識率は合意していない。石の分類精度は成功条件に含めない。

## 実写検証が必要な仮説・未確認事項

| 項目 | 現時点の扱い |
| --- | --- |
| 卓上スタンドで盤全体・四隅を写せる高さと角度 | 可能と想定して始めるが、安定して撮れるかは未確認。数値は未決定 |
| 斜め撮影での石による隠れ | 程度は未測定。今回の画像で観察し、後の石認識への影響は別途検証する |
| 室内照明での線の見やすさ・反射 | 実画像で確認する。暗所・強い反射等の追加条件は結果を見て検討する |
| 四隅の調整による中央・辺の位置合わせ | 目視確認が可能か未検証。四隅が合うだけで全交点が合うとは扱わない |
| 操作時間 | 未測定。1〜2分は目標であり実績ではない |

射影変換で石に隠れた交点の見た目が復元できるとは扱わない。今回の成功は、将来の石認識や実対局での自動記録の成功を保証しない。

## 今回の対象外と保留事項

- 自動四隅検出：最初は手動方式で開始する。「自動で候補を出し、必要なら人が微調整する」方式は将来の検討候補。AI等の具体的手法・導入時期・精度は未決定。
- 保存画像の選択、指定点の保存・再利用、拡大等の補助操作：今回の合意に含めず、必要性を後で判断する。
- 石認識、動画記録・追跡、合法手・捕獲・パス・途中開始の扱い、履歴修正、SGF出力、KataGo：今回の試作の対象外。
- 撮影開始後にスマホの位置・向きを変えて記録を継続する機能：だいぶ先の検討事項。今回の静止画像には含めない。
- 将来の対局中・対局後に許容する操作負担、固定中のずれへの対応、映像保存の方針：未決定。今回の手動指定の合意から推定しない。
